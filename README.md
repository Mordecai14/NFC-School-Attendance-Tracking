# Bienvenido a tu aplicación Expo 👋

Este es un proyecto [Expo](https://expo.dev) creado con [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Primeros pasos

1. Instalar las dependencias

   ```bash
   npm install
   ```

2. Iniciar la aplicación

   ```bash
   npx expo start
   ```

La salida muestra opciones para abrir la aplicación en:

- un [build de desarrollo](https://docs.expo.dev/develop/development-builds/introduction/);
- un [emulador de Android](https://docs.expo.dev/workflow/android-studio-emulator/);
- un [simulador de iOS](https://docs.expo.dev/workflow/ios-simulator/);
- [Expo Go](https://expo.dev/go), un entorno de pruebas limitado para explorar el desarrollo de aplicaciones con Expo.

Para comenzar a desarrollar, editar los archivos del directorio **src/app**. Este proyecto usa [enrutamiento basado en archivos](https://docs.expo.dev/router/introduction).

## Reiniciar el proyecto

Cuando sea necesario, ejecutar:

```bash
npm run reset-project
```

Este comando mueve el código inicial al directorio **example** y crea un directorio **src/app** vacío para comenzar a desarrollar.

### Otros pasos de setup

- Para configurar ESLint y ejecutar lint, usar `npx expo lint` o consultar la guía sobre [uso de ESLint y Prettier](https://docs.expo.dev/guides/using-eslint/).
- Para configurar tests unitarios, consultar la guía de [testing unitario con Jest](https://docs.expo.dev/develop/unit-testing/).
- Para conocer el setup de TypeScript de esta plantilla, consultar la guía sobre [uso de TypeScript](https://docs.expo.dev/guides/typescript/).
